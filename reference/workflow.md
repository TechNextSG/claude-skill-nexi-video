## The strict sequence (bash, from `~/ClaudeWork/nexi-tutorial`)

```
python build_film.py <name>                                   # lint runs here: an ERROR = not built
NT_VIDEO=<name> python render.py probe                        # load check + caption timeline
NT_VIDEO=<name> python render.py sheet 6.5,9.4,12.0 r1         # quick contact sheet while designing
NT_VIDEO=<name> NT_PORT=3987 CDP_PORT=9387 CDP_PROFILE=profile-nt-a python render.py audit 5 > qa/audit-<name>.log 2>&1
python layout_audit.py <name>                                 # ALWAYS right after the audit
python qa/_strip.py <name> 2.5                                # look: empty frames, balance, design
python gate.py <name> --pre                                   # must PASS before rendering
NT_VIDEO=<name> NT_PORT=3990 CDP_PORT=9390 CDP_PROFILE=profile-nt-x python render.py mp4 > out/render-<name>.log 2>&1   # refuses on a failing pre-gate
python deliver.py sheet <name>                                # LOOK at qa/<name>-final.jpg and qa/<name>-cta.png
python deliver.py copy <name>                                 # full gate → Drive → md5 (no bypass)
python sync_source.py                                         # after the batch
```

- **Debug only:** `NT_FORCE_RENDER=1` renders a draft despite a failing pre-gate. The draft still cannot be delivered until the gate passes for the same build.
- **Renders made before stamps existed:** `python gate.py <name> --adopt` stamps them, but only when every source is older than the MP4. Any engine or film change after the render means re-render.
- **An engine change** (any `engine_*.js`, `lib.js`, `set.js`, `ui.js`, `intro.js`, `nexi-core.js`) changes every film's fingerprint. Every film needs a fresh audit before its next render. That is intended.
- **New film:** add it to `render.NAMES`, `render.LIMIT` (0.68–0.7, required), `deliver.SRC` + `DST`, and `audio_t.MAIN`. G3 fails otherwise.
- **Audio-only fix:** `ffmpeg -i out/<f>.mp4 -an -c:v copy out/<f>.v.mp4 && python mux.py <name>`, then delete the `.v.mp4` and `.wav`. The build stamp stays valid because the video stream is unchanged; the gate re-measures the audio.
- **Rendering speed:** about 20 fps per Chrome. Up to six Chrome jobs (renders or audits) run at once on ports 3987–3995 / CDP 9387–9395, each with its own profile. Port 3984 is taken by a preview server. A 60 s audit takes about 75 s.
- **"F is not defined":** if a render dies with it, something outside killed the page; rerun.

## Waivers (`qa/waivers/<film>.json`)

```json
[{"rule": "cut", "match": "chapter", "t0": 10.0, "t1": 11.5, "reason": "the chapter band slides in from the right edge by design (walkthrough series)"},
 {"check": "voice-ratio", "reason": "whooshes sit between lines by design; music measured 10.6 dB under the voice"}]
```

- Only for **intended** effects, never to save time.
- A finding waiver needs a rule, a time window and a reason of 20+ characters; `match` narrows it to a message.
- Audio waivers name a `check`: `lufs`, `voice-ratio`, `music-under` or `music-gaps`. A true peak (A2) is never waived: lower the effect or the limiter.
- Unused waivers are reported; delete them.
- Truth and brand lint errors cannot be waived at all.

## Writing patches and films (tooling gotchas)
- Bash heredocs that contain JavaScript break, and the Bash tool halves backslashes. Write JS and patch scripts with the Write tool, then run them.
- The Write tool turns `\u2019`-style escapes into the literal character. That is fine in JS, but patch match strings must use the literal character too.
- Patches use assert-and-replace (`assert s.count(a) == 1`), so a stale match fails loudly instead of silently.
- Never `git add -A` in the shared hub clone.
- A module that re-wraps `sys.stdout` closes the previous wrapper; use `sys.stdout.reconfigure(...)`.
